🔑 CORE AUDIT FIELDS (All Services)
═══════════════════════════════════════════════════════════════════════════════

Every entity now tracks:

  createdAt    → ISO 8601 timestamp when record created
  createdBy    → User ID who created the record
  updatedAt    → ISO 8601 timestamp of last modification
  updatedBy    → User ID who last modified the record

Additional for Purchase Orders:

  submittedAt  → When PO submitted for approval
  submittedBy  → Who submitted the PO
  approvedAt   → When PO was approved
  approvedBy   → Who approved the PO
  rejectedAt   → When PO was rejected
  rejectedBy   → Who rejected the PO


🚀 HOW TO USE
═══════════════════════════════════════════════════════════════════════════════

1. START THE APPLICATION
   $ docker compose up --build

2. VERIFY SERVICES ARE RUNNING
   $ curl http://localhost:8080/api/suppliers/health
   $ curl http://localhost:8080/api/budgets/health
   $ curl http://localhost:8080/api/purchase-orders/health
   $ curl http://localhost:8080/api/analytics/health

3. CREATE A SUPPLIER (with audit logging)
   $ curl -X POST http://localhost:8080/api/suppliers \
     -H "Content-Type: application/json" \
     -H "X-User-Id: procurement@example.com" \
     -d '{
       "name": "ABC Technologies",
       "email": "vendor@abc.com",
       "gstNumber": "29ABCDE1234F1Z5",
       "category": "IT Equipment"
     }'

4. VERIFY AUDIT LOG ENTRY
   $ docker exec -it spendwise-supplier-db psql -U postgres -d supplier_db -c \
     "SELECT * FROM supplier_audit_log;"

5. SEED TEST DATA
   $ bash scripts/seed-test-data.sh  (or use curl examples from guide)

6. QUERY ANALYTICS OVERVIEW
   $ curl http://localhost:8080/api/analytics/overview | jq .
